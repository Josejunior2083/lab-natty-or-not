# Projeto Natty or Not: Explorando as IAs Generativas no Fisiculturismo

## Descrição

Este projeto explora o uso de Inteligências Artificiais Generativas para criar conteúdo relacionado ao fisiculturismo, com foco na distinção entre atletas naturais e não naturais. Foram utilizadas diversas ferramentas de IA para geração de texto, imagem e até mesmo combinação de mídias para criar vídeos curtos informativos.

## IAs Generativas Utilizadas

*   **Texto:** Bard (Google AI)
*   **Imagens:** Midjourney
*   **Narração:** ElevenLabs

## Considerações

O uso de IAs Generativas oferece um grande potencial para a criação de conteúdo informativo e criativo. No entanto, é importante utilizá-las com responsabilidade, evitando a geração de conteúdo enganoso ou prejudicial. Neste projeto, procurei abordar o tema "Natty or Not" com cautela e respeito, buscando apresentar informações relevantes de forma clara e objetiva.
